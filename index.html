手机上

顶部三档：描述 / 参数 / 画面；生成后自动切到画面，底栏始终可以生成或停止。大图预览支持左右滑翻页、双指缩放，1× 时下滑关闭。作品库卡片点图进入预览，收藏、参数、导出、删除都在预览里完成。

日常用法

生成时主画面会同步显示每一步的采样预览，左侧栏底部显示进度与剩余时间。左侧按工作流从上到下排：模式与预设、画面描述、画质与张数、尺寸、采样、步数与强度、种子、高清放大、引擎细节、模型与 LoRA；参数栏自己滚动，生成按钮和发送摘要固定在栏底，始终可见。画质里的「抽卡 / 速写 / 标准 / 精细 / 高清」会自动设置步数、CFG 与高清放大，档位会随当前模型变化（MiaoMiao 标准 32 步，Silvermoon 标准 28 步）。「抽卡」只在 Anima 的文生图出现：自动挂 Turbo LoRA，10 步 / CFG 1 / Euler·Beta，张数可选 1 / 2 / 4 / 8 / 12（其余画质档仍为 1 / 2 / 4）；切到图生图时抽卡档会自动转成细化参数（关 Turbo、28 步实采 / CFG 4），张数收回 1。从图库把抽卡图送去重绘时会自动切到细化参数，之后可在参考图卡片里点「细化预设」加一组细节词（预设词与 LoRA 触发词都追加在转写后的 Tags 行）。切换模型会自动套用该模型的推荐采样与记住的参数；想固定同一张脸和构图时，打开「固定种子」；「换一张」会重新随机。批量多图会按顺序生成，画布下方出现本批对比条，拼图另存在 txt2img-grids。

图生图先选参考图，用重绘幅度控制变化大小。图生图按所选步数实际采样，不会被重绘幅度折算成更少步数。参考图长边超过 1280 会等比压到 1280；PNG 来源保持无损（超过约 6MB 才转 JPEG），避免反复重绘叠加压缩噪点。画质里的「抽卡」和「高清」只出现在文生图：重绘没有 Hires 二采，切到图生图时这两档会自动退回当前参数。生成的画面可以一键「送去重绘」，继续细修；送去重绘时张数固定为 1。从图库送去重绘时，如果原图带提示词，提示条上的「载入原词」可一键载入原提示词和负面词；「查看参数 → 载入参数」也会恢复重绘幅度，图生图作品会自动切到图生图模式（参考图需重新选择）。左侧参数栏可切换采样组合（SDXL：均衡 / 写实 / 结构 / 柔和 / 低步；Anima：均衡 / 厚涂 / 结构 / 柔和 / 低步；Krea 2：Euler·Simple / Euler·Beta / Euler a / 6 步极速），步数与强度仍由画质档或滑杆控制；「引擎细节」可改 CLIP 跳过层（Pony / SDXL 用 2）、VAE / 模块与 Hires 放大算法。Anima 与 Krea 2 底模会多出 Shift 滑杆（Krea 2 默认 1.15）。Hires 二次步数自动取基础步数一半（至少 8 步），8GB 显存优先 1.25x + Lanczos。Krea 2 Turbo 是 12B 流匹配 DiT + Qwen3-VL 4B 编码器：标准档 8 步 / CFG 1 / Euler·Simple / Shift 1.15，首次加载权重较慢，之后复用系统页缓存。所有设置会自动保存在本机浏览器，最近作品只在当前页面会话中保留。

风格条上有三个库：角色收录近 400 个成年角色，点一次把角色、系列与外观整包写入；弹窗顶部可切到全年龄库，收录 271 个经典 IP：Vocaloid / UTAU、东方、番剧、VTuber，以及王者荣耀、无畏契约、原神、崩坏：星穹铁道、英雄联盟、守望先锋、明日方舟、永劫无间和经典单机角色；只写非性化的正常服装与外观，应用时会自动剔除 adult / mature female 等成人词并把评级切到「安全」。画师按 Anima 画师标签混合；灵感与标签里有 720+ 个正向标签和 170+ 个负面标签，全部中文显示，点击写入英文。三个库都支持搜索与分类跳转，角色与标签会显示当前选中状态。右上角「外观」菜单可选浅色、深色或跟随系统。

「画面描述」可以直接写中文自然语言。点「生成画面」时会先调用本机 Qwen3.5-4B（CPU 推理，不占显存、不联网），按当前底模自动写成英文提示词：Anima 写成三句画面叙事加一行 Danbooru 标签，Krea 2 写成完整自然语言描述（不带 Tags 行、不套画师标签惯例），Pony / SDXL 写成纯标签。英文草稿会显示在输入框下方，可「换一版 / 编辑 / 复制 / 收起」；生成时自动使用草稿，输入框里的中文原样保留。纯英文标签默认原样发送、不调用模型；点过「转写预览」后生成时改用那份草稿（可能带上质量前缀与风格标签），草稿失效则回到原样发送。首次转写要加载模型，约 10–30 秒。

「画面描述」标题右侧的「评级」按钮由你手动决定评级：默认「自动」不写任何评级标签（保持 raw 直出）；选「安全 / 敏感 / NSFW / 露骨」后，生成时会在标签里写入对应评级，Anima 用 safe / sensitive / nsfw / explicit，Pony 用 rating_safe / rating_questionable / rating_explicit（Pony 没有敏感档，敏感与 NSFW 都落到 rating_questionable）；Krea 2 不写评级标签，评级只决定转译时是否保留成人细节。评级也会参与 4B 转译：NSFW / 露骨档会要求模型保留你写出的成人动作和身体细节、不写委婉语，并把对应评级标签写进英文草稿的 Tags 行；切换评级后旧草稿会标记为需重新转译。中文输入框始终原样保留。

显存与保存

8GB 显存实测（832×1216；桌面壁纸、浏览器等常驻程序会占用显存，耗时可能上下浮动 20–50%）：MiaoMiao bf16 / 32 步约 35–65 秒，峰值 7.0–7.5GB；Silvermoon INT8 / 28 步约 26–40 秒，峰值 5.3–7.2GB。刚切换模型的第一张还要加载权重：MiaoMiao 约 30–60 秒，Silvermoon 约 20–40 秒。MiaoMiao 开 Hires 1.25x / 32 步实测约 94 秒，峰值 7.5GB，已经接近上限；Silvermoon 同档 28 步约 47 秒。1.5x 不建议直接上。成图自动保存在 D:\AI\sd-webui-forge-neo\output\txt2img-images，图生图在 img2img-images。
